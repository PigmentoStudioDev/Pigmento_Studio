## Decisiones tomadas dentro del alcance
- `alt` viaja como objeto `{ es, en? }` y `source` como unión `{url} | {base64, filename,
  mimeType}`, como decía D5. El `inputSchema` que sale por el cable lo muestra como `anyOf`
  con `required` por rama: legible para un modelo.
- `sanitizeFilename` acepta una URL o un nombre: si parsea como URL usa su `pathname`. Así
  el mismo helper sirve a las dos ramas y una URL sin path da `archivo`, no el host.
- Las respuestas de la tool propia son JSON en el `text` (con `isError: true` en los fallos),
  no prosa: es lo que el oráculo y un cliente pueden parsear. Las del plugin son prosa con un
  bloque JSON; no se tocan.
- El oráculo compara nombres + `required` + props de primer nivel, no el JSON Schema entero:
  una descripción que mejora no es una ruptura.

  antes de la petición. Test: el `fetch` al host prohibido nunca ocurre.
- **MEDIUM** base64 se decodificaba entero antes de medir: tope por longitud del texto
